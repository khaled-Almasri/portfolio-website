# Portfolio – Khaled Almasri

Persönliches Portfolio, gebaut mit Next.js und Tailwind CSS.

## Inhalte ändern

Alle Texte, Projekte und Skills stehen in [`src/content/site.ts`](src/content/site.ts).
Das Profilfoto liegt unter `src/assets/profile.png`.

## Lokal starten

```bash
npm install
npm run dev
```

Danach http://localhost:3000 öffnen.

## Deployment

Das Repository mit Vercel verbinden – Vercel erkennt Next.js automatisch,
es sind keine weiteren Einstellungen nötig.
